### PANTHER GUI

A modern graphical interface for **PANTHER**, designed to make network protocol testing and experiment management more accessible. Developed as part of my master's thesis and my largest contribution to a project so far.

**Technologies:** Python · NiceGUI · YAML · Docker · Plugin Architecture

* Visual scenario and topology design
* Plugin management
* Live YAML configuration preview and synchronization
* Experiment launching and monitoring
* Automated configuration validation

### Time Event Logging & Monitoring System

A cloud-native system designed to **capture, centralize, and monitor time-based application events** across distributed services. The project focused on building reliable infrastructure for event logging, service health monitoring, and deployment across multiple virtual machines.

**Technologies:** Docker · Docker Swarm · Azure · Microservices · CI/CD · Centralized Logging

* Distributed microservice architecture deployed across multiple virtual machines
* Centralized logging for events generated across services
* Service health monitoring and operational visibility
* Automated deployment and CI/CD workflows
* Containerized services orchestrated using Docker Swarm

### Reddit Developer Bot

An automated Reddit bot designed to interact with and process Reddit content programmatically.

**Technologies:** Python · Reddit API · Automation

* Automated interaction with Reddit content
* API-driven processing of posts and comments
* Event-driven automation and background processing
* Designed with modular components for extending bot functionality

## Private Projects

### Indoor Navigation Mobile App

An Android indoor navigation application developed as a final-year project using Bluetooth iBeacon technology. I worked with a well-known software services company, **Ebryx**, alongside four team members. We significantly improved the cost-effectiveness of the initial proposal, and the project was later commercialized by the company for larger use cases.

**Technologies:** Kotlin · Jetpack Compose · Firebase · Unity · iBeacon · MVC

* Kotlin-based Android application
* Indoor positioning using iBeacon technology
* Real-time Firebase backend
* Interactive navigation interface
* Developed in collaboration with an industry partner

### Shopping Cart Microservices

A distributed shopping cart system designed around a **microservices architecture**, focusing on service separation, inter-service communication, and scalable backend design.

**Technologies:** Microservices · REST APIs · Docker · Databases

* Independent services for different business capabilities
* RESTful inter-service communication
* Containerized services
* Designed around scalability and separation of concerns

### Finly: Personal Financial Consultant

A **Generative AI financial assistant** built around retrieval-augmented generation. Combining conversational AI with real-time financial data and visualization.

**Technologies:** Python · LangChain · RAG · Streamlit · OpenAI API

* Retrieval-based financial question answering
* Context-aware responses
* Interactive Streamlit interface
* Data visualization and charting
